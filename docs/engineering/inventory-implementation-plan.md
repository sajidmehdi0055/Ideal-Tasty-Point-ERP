## Checks and independent review required for every future slice

QA maps approved Given/When/Then criteria to executed unit, integration, regression and acceptance evidence. Run applicable lint/type checks and record exact commands/results. Integration tests use approved contracts and must expose missing dependencies; a stub is not proof of a working external module. Required unavailable checks remain BLOCKED. Assess concurrency/repeat requests and rejected actions where stock/data safety requires it without inventing business outcomes.

Security & Code Review Agent must differ from the implementer. Review permissions, secrets, history/data safety, auditability and cross-module violations. Architecture reviewer checks schemas/migrations/contracts when changed. Findings return to implementer, QA and independent re-review. Manager verifies traceability/documentation/risks; only owner-authorized staging/commit/merge follows. Destructive data operations require separate explicit approval and cannot override the historical hard-delete prohibition.
